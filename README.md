# Mongil: Star Dive Knowledge Base

Canonical, version-controlled account knowledge for roster-specific optimization.

## Data domains

- `data/`: objective game records only.
- `account/`: mutable account ownership and investment.
- `testing/`: repeatable experiments and historical results.
- `strategy/`: recommendations and hypotheses derived from the other domains.
- `templates/`: schemas for new records.

Every nontrivial claim carries a confidence label: `official`, `in_game`, `tested`,
`community`, `hypothesis`, or `unknown`.
