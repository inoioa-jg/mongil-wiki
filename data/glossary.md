# Glossary

Terms below are operational definitions; exact game formulas remain unknown unless linked.

- **Awakening (A#):** character duplicate/progression tier from A0 through A6.
- **Signature/Fate (F#):** signature progression tier from F0 through F6.
- **Link:** monsterling effect activated only by the monsterling in slot 1 (`in_game`).
- **Rank:** monsterling progression effect; slots 1–3 contribute rank (`in_game`).
- **Trait:** monsterling stat/property contribution; slots 1–3 contribute traits (`in_game`).
- **Field time:** duration for which a character occupies the active combat slot, including animation/lock time relevant to opportunity cost.
- **Neutralization:** game mechanic/value whose exact formula is currently `unknown`.
- **Elemental Weakness:** game mechanic/value whose exact formula is currently `unknown`.
- **RES reduction:** debuff reducing the target's elemental resistance; stacking/formula is `unknown` unless separately tested.
- **DEF shred:** debuff reducing target defense; stacking/formula is `unknown` unless separately tested.
